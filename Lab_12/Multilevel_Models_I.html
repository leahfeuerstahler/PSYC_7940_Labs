Overview

  • Today we will learn how to fit multilevel models in brms.

  • In previous labs, each parameter applied to everyone included in the model. However, this method ignores within-person variation.

  • To allow for individual differences, we can use multilevel modeling.

  • Instead of using a separate intercept for each observation, the multilevel approach uses the method of partial pooling to model a distribution of intercepts.

Multilevel Models

To illustrate, let’s load in the TDF.csv data, along with the tidyverse and brms packages.

library(tidyverse); library(brms)
d1 <- read_csv("TDF.csv")

\(\sigma \sim Exp(.25)\)

Multilevel Models

We can allow for random intercepts using the (1 | ID) syntax, where ID is the clustering variable.

  • This is the same syntax used by lmer and glmer for multilevel models.

For our height and weight example, our formula looks like this:

brm_form1 <- Weight ~ HeightC + (1 | Name)

Priors

As we see in the class column, we have a new parameter class labelled sd. This is the prior for the standard deviation of intercepts.

  • Recall: intercept = predicted weight for average height

  • We may expect some individual variability. We will try an Exponential(.5).

prior1 <- prior(normal(66.5, 2), class = "Intercept") +
          prior(exponential(.5), class = "sd") +
          prior(normal(1, .5), class = "b") +
          prior(exponential(.25), class = "sigma")

Prior Predictive Simulation

predict1 <- brm(brm_form1, d1,
                family = gaussian(link = "identity"),
                prior = prior1, cores = 4, sample_prior = "only")

Prior Predictive Simulation

Our choice of sd prior affects the width of the band of predicted observations, so we want to make sure this makes sense.

  • method = "posterior_predict": plot the distribution of predicted observations

  • re_formula = NULL: include all cluster effects

conditional_effects(predict1, method = "posterior_predict", re_formula = NULL)

Model Fitting

m1 <- brm(brm_form1, d1,
          family = gaussian(link = "identity"),
          prior = prior1, cores = 4)

Model Results

Notice that even for this relatively simple multilevel model, estimation is not as efficient as with other models. We need to be cautious to run enough iterations for the inferences we want.

d2 <- read_csv("language.csv")

Priors

It is a long list, but we can simplify matters by specifying the same priors for each set of index variables. There is no need to specify priors for each coef (unless you want to!). Here, we use the priors from lecture.

prior2 <- prior(normal(3, .5), class = "b", coef = "Intercept", nlpar = "c") +
          prior(normal(0, .5), class = "b", nlpar = "a") +
          prior(normal(0, .5), class = "b", nlpar = "b") +
          prior(exponential(2), class = "sd", nlpar = "c")

Adding On

We can set multiple types of random effects. For example, we could consider the random effects of both persons and items.

For example:

d3 <- read.csv("language item.csv")
brm_form3 <- bf(response ~ a + b + c + d,
                    a ~ 0 + tasktype,
                    b ~ 0 + group,
                    c ~ (1 | ID),
                    d ~ 0 + (1 | item), nl = TRUE)
